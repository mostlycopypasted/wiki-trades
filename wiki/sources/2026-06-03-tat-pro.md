## Technical Trading Rules & TAT V2 Dashboard Playbook

- **Default EMA Filtering (TAT V2)**: The V2 dashboard introduces default Moving Average filters. Bullish signals only display when price is above both the 21 EMA (short-term) and the 133 EMA (long-term). Bearish signals only display when price is below both.
- **Alert Creation Order constraint**: The alerting system takes the first command set when the alert is created. Disabling the EMA filter *after* creating the alert on a watch list will not update the active alert behavior; the alert must be deleted and re-created.
- **Watchlist Sizing Strategy**:
  - **Filtered Scans (MA Enabled)**: Best for massive watchlists (e.g., 10,000 tickers) to automatically filter out noisy sideways consolidation and keep inputs manageable.
  - **Unfiltered Scans (MA Disabled)**: Best for tight, hand-curated watchlists (e.g., 50 tickers) to ensure high-yield, deep-reversal signals are not missed.
- **Deep Reversals vs. Gentle Base Pullbacks**: Filtered scans are optimized for gentle pullbacks off a rising base. However, they block sharp, deep corrections since price is often below the 20 EMA when the signal triggers. Unfiltered scans permit entries on these deep-reversal momentum setups.
- **The "1+1" Reversal Confirmation**: A close above the short-term 20/21 EMA combined with a TAT horizontal breakout level provides a highly reliable confirmation for short-term trend reversals on H1/M15 charts.
